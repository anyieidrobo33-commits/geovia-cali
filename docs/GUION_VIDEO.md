# Guion del video de socialización (máximo 10 minutos)

Requisito de la guía: **todos los integrantes con la cámara encendida durante toda la grabación**. Se recomienda Zoom, Meet o Teams grabando pantalla compartida + cámaras. Tener abiertos antes de grabar: la app en el computador, el celular (con la app instalada) duplicado en pantalla (scrcpy, Vysor o “Duplicar pantalla”), GitHub y Supabase.

| Tiempo | Segmento | Qué mostrar | Quién |
|---|---|---|---|
| 0:00–0:45 | Presentación | Integrantes, problema (organización de reportes viales en Cali), objetivo y alcance académico (no es canal oficial). | |
| 0:45–1:45 | Arquitectura y repositorio | GitHub: estructura de carpetas, pestaña **Actions** en verde, README. Tecnologías: React + TypeScript, Leaflet, Supabase (PostgreSQL + PostGIS, RLS), PWA, Vercel. Metodología CDIO. | |
| 1:45–4:00 | Reporte ciudadano (celular) | Abrir la app desde el **ícono instalado** → Reportar → Usar mi ubicación → aviso de duplicado (si aplica) → categoría, severidad, descripción → **tomar foto con la cámara** → consentimiento → Enviar → código de seguimiento. | |
| 4:00–5:30 | Mapa y consulta | Mapa con marcadores por categoría, filtros (tipo, fecha, barrio), vista Lista (accesibilidad), ficha de un reporte con fotos e historial. Seguimiento por código. | |
| 5:30–7:20 | Administración | Ingresar como revisor → Panel (indicadores, pestañas, búsqueda) → abrir el reporte recién creado → **Pasar a revisión** y **Validar** con motivo → bitácora → ahora aparece en el mapa público. Intentar transición no permitida (no aparece botón). Exportar CSV. | |
| 7:20–8:50 | Pruebas y evidencia TRL5 | Supabase SQL Editor: ejecutar `pruebas_seguridad_y_reglas.sql` → 17 APROBADO. Terminal o Actions: `npm test` → 27 aprobadas. Mencionar prueba en celulares reales y la leyenda de rendimiento del mapa. | |
| 8:50–10:00 | Limitaciones y cierre | Límites (no certifica daños, datos de demostración marcados), trabajo futuro (Capacitor/APK, Play Store, integración institucional, notificaciones). Agradecimiento. | |

**Consejos:** ensayar una vez completo; tener un reporte “recibido” listo por si falla la señal; subir el video a YouTube como *No listado* y verificar que el enlace abre sin iniciar sesión.
