# Reportes de campo

Registro fotográfico de nueve afectaciones de la malla vial tomadas en Santiago de Cali por el equipo del proyecto.

- `reportes.json`: coordenadas, código Plus de Google Maps, tipo, severidad percibida, dirección, sector y descripción.
- `reporte-01.jpg` … `reporte-09.jpg`: fotografías redimensionadas (máx. 1600 px) y **sin metadatos EXIF**, igual que las procesa la app.

Se cargan con `npm run cargar:reportes`, que los envía como ciudadanos sin cuenta (una sesión anónima por reporte). Ver la [guía de despliegue](../../../docs/GUIA_DESPLIEGUE.md#5-cargar-los-reportes-de-campo-3-min).
